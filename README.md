# Sentinel — mini demo

A raw-data-to-branded-PDF engine, demonstrated by rendering the same data through
three completely different brand templates (Standard / Barbie / Oppenheimer). A
generic, sanitized miniature of one feature from a larger internal tool suite —
no employer branding, no real case data.

Single static page, no build step, no dependencies beyond a CDN-hosted jsPDF.

## Deploy on Render

**Blueprint (try first):** New + -> Blueprint -> connect this repo -> Apply.

**Manual (if that errors):**
1. New + -> Static Site -> connect this repo
2. Build Command: leave empty
3. Publish Directory: `.`
4. Create Static Site
